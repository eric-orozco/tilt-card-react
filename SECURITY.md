# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

If you discover a security vulnerability in `@eao/tilt-card`, please **do not open a public issue**. Instead, email the maintainer directly or open a private security advisory on GitHub.

We aim to respond within 48 hours and publish a fix as soon as possible. All reports will be credited unless you request anonymity.
